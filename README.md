# Painel de Engajamento

Painel estático pronto para GitHub Pages.

## Arquivos
- `index.html` — estrutura do painel
- `style.css` — visual preto/vermelho responsivo
- `script.js` — formulário, cálculo do total e envio do pedido ao WhatsApp

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os três arquivos (`index.html`, `style.css`, `script.js`).
3. Em **Settings → Pages**, selecione a branch principal e a pasta `/root`.
4. Salve e aguarde a publicação.

O botão de pedido abre o WhatsApp para o número configurado no código.
